# ZMart Full Stack App

A full stack web app using:

- Vite + React + TypeScript
- Tailwind CSS
- FastAPI + Uvicorn
- SQL Server (via SQLAlchemy/pyodbc)

## Usage

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
